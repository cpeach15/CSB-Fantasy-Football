# Commissioner's report

Drop one file per week in this folder, named like `2026-wk07.md` (season, then week number).
The site shows the newest one at the top of This Week, with earlier weeks a tap away.

The first lines can say who wrote it and give it a title, then a blank line, then the write-up.
Leave a blank line between paragraphs. Hashtags like #RevengeGame get highlighted.

```
by: Pat K.
title: Chaos in the late window

Paragraph one...

Paragraph two...
```

To add one on GitHub: open this folder, click Add file > Create new file, name it, paste the text,
and click Commit changes. The site rebuilds in a couple of minutes.
